## 🎯 Tentang

**FORMULA** (Informatika dan Multimedia) adalah ekstrakurikuler di SMAN 1 Mojosari. Website ini adalah **Central Platform** yang dirancang sebagai ekosistem digital terpadu untuk:

- 🏫 **Profil organisasi** — etalase publik
- 👥 **Manajemen anggota** — data & role terpusat
- 📊 **Project management** — tracking project & task
- 📚 **Learning platform** — modul & progress belajar
- 📅 **Event & attendance** — kelola kegiatan & absensi
- 🏆 **Portfolio & achievements** — showcase karya anggota
- 🎓 **Alumni network** — jejaring mantan anggota

**Konsep:** *"Website profil + dashboard organisasi + sistem manajemen anggota + project management + learning platform + documentation center dalam satu ekosistem."*

---

## ✨ Fitur Utama

### 🌐 Public Website
- Home dengan hero, statistik, program, project, berita, galeri, achievement
- About: sejarah, visi misi, struktur, divisi, timeline
- Programs: program kerja + filter kategori + FAQ
- Projects: grid project + filter status + modal detail
- Members: direktori anggota publik (privacy-safe)
- News: berita, pengumuman, artikel + load more
- Gallery: masonry foto/video + lightbox
- Achievements: prestasi + timeline + sertifikat
- Alumni: direktori + stories
- Contact: form + validasi + WhatsApp + maps

### 🔐 Authentication
- Login & Register multi-step
- Password strength indicator
- Show/hide password toggle
- Role-based access control
- Session management

### 📊 Member Dashboard
- Overview personal
- My Tasks + status
- My Projects + progress
- Attendance summary
- Notifications
- Upcoming events
- Profile management

### 🛠️ Admin Dashboard
- Member management (CRUD)
- Project & task management
- Content management (CMS)
- Event management
- Document center
- Role & permission
- Analytics
- Activity log

### 🚧 Maintenance System
- Halaman maintenance dengan animasi tingkat tinggi
- Auto-redirect ke semua halaman
- Bypass admin via query string
- Countdown ETA
- Preview mode
